# Simple Mac Keyboard Control 0.1.0

- Use volume and mute keys with fixed-volume audio interfaces and USB DACs.
- Adjust external-display brightness using DDC/CI, with software dimming when hardware control is unavailable.
- Native menu-bar controls, linked display brightness, permission guidance, and launch at login.
- Stable and beta app identities, light and dark icons, and signed Sparkle updates.

Requires macOS 14.4 or later. Hardware DDC support currently requires Apple silicon; software dimming is available on supported external displays.
