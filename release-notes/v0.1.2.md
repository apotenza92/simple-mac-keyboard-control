# Simple Mac Keyboard Control 0.1.2

- Redesigned the menu using native macOS menus, square checkboxes, and sliders that follow the system accent colour. Fixed colour changes on hover and layout issues when opening Permissions.
- Added an update schedule menu with On startup, Daily, Weekly, Monthly, and Never. Stable defaults to weekly; beta defaults to checking at startup.
- Refreshed onboarding with larger icons and clearer permission controls. Onboarding resumes after a permissions restart and stays incomplete until you finish it.
- System Audio Recording now starts directly from Allow, without opening System Settings. Integrated PermissionFlow for keyboard permission setup.

Available for Apple silicon and Intel in both stable and beta app identities. Audio processing and DDC transport are unchanged.
