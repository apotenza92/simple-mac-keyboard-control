# Simple Mac Keyboard Control

**Volume, mute, and brightness keys that just work.**

A small native menu-bar app for keyboard volume, mute, and external-monitor
brightness on connected Mac hardware. No mixer, equalizer, or shortcut editor.

## Visual identity

- Charcoal: `#272B32` — primary surface and text.
- Warm amber: `#F4B544` — brightness accent.
- Off-white: `#F2F0EB` — sound key and light surfaces.
- Typography: system SF; use sentence case and plain, functional language.
- App icon: two physical keycaps, one sun and one speaker, on a charcoal tile.
- Menu bar: monochrome system keyboard symbol; no coloured status-bar logo.

The app icon is generated by `scripts/render-icon.swift`, so every icon size can
be reproduced without a design-tool dependency. The HUD keeps native macOS
materials rather than applying marketing colours to system controls.

## Naming and compatibility

Public app name: **Simple Mac Keyboard Control**.
Development display name: **Simple Mac Keyboard Control Dev**.
Repository and workspace folder: `simple-mac-keyboard-control`.

Internal Swift modules, bundle IDs (`com.apotenza.KeyControl` and `.dev`), signing
identity, and the installed `~/Applications/KeyControl Dev.app` path remain stable
to avoid unnecessary permission migrations. These are implementation identifiers,
not public branding.
